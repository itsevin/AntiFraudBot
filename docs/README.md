> [!TIP]

> [!IMPORTANT]
> 所有配置示例都使用占位值。请勿把真实 QQ 号、聊天记录、数据库、Token、API Key 或本地 `.env` 文件提交到版本库。

找不到答案时，可以先查看项目的 [Issue](https://github.com/itsevin/AntiFraudBot/issues)，确认没有重复问题后再提交一个包含环境、复现步骤和日志脱敏片段的新 Issue。
