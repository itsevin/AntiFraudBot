# 🎮 使用指南

[文档中心](README.md) · [English](en/user-guide.md) · [安装与部署](安装部署.md)

## 1. 角色与权限

| 角色 | 可用能力 |
|---|---|
| 普通用户 | 帮助、签到、答题、积分、AI 鉴诈、反诈咨询 |
| 群管理员/群主 | 普通能力 + 当前群功能开关 |
| NoneBot 超级用户 | 管理指令和全局维护能力 |
| Web 管理员 | 登录安全大屏并调用受保护的管理 API |

群管理员权限通过 OneBot 群成员角色判断；超级用户来自 `.env.prod` 中的 `SUPERUSERS`。

## 2. 功能菜单

发送：

```text
帮助
```

机器人会返回当前可用功能。命令前缀由 `COMMAND_START` 决定，默认允许直接发送中文命令。

## 3. 风险检测

### 关键词检测

机器人从数据库读取启用的关键词。当消息命中时，它会发送风险提示并写入检测日志。

群管理员可以使用：

```text
开启 关键词检测
关闭 关键词检测
查看配置
```

检测结果是规则辅助，不代表司法或平台认定。普通词语可能在特定语境中产生误报，管理员应结合实际群聊场景维护词库。

### URL 风险检测

配置阿里云内容安全凭据后，机器人可以把消息中的 URL 提交给对应服务检测。该能力可能产生费用，并受第三方服务条款、地域和数据政策约束。

未配置密钥时应关闭 URL 检测，不要使用公开示例凭据。

## 4. AI 智能鉴诈

```text
鉴诈 您涉嫌违规，请立即点击链接完成资金验证
```

AI 会返回风险等级、诈骗类型、分析说明和建议。输入可能被发送给配置的模型服务，因此：

- 不要提交验证码、密码、身份证号、银行卡号或完整聊天记录；
- 对资金操作保持人工复核；
- 模型结论可能出错，不应作为唯一判断依据。

如果 AI 未配置，机器人会提示该功能不可用。

## 5. 智能对话助手

常见触发方式：

```text
反诈咨询 如何识别冒充客服退款？
AI咨询 对方让我共享屏幕安全吗？
@机器人 这个兼职刷单可信吗？
```

助手支持短期多轮上下文和基础知识检索。当前图片知识库 OCR 尚未完成，因此不能把所有图片内容视为可检索文本。

可以发送清理上下文命令，避免后续回答继续使用旧对话。具体命令以机器人 `帮助` 输出为准。

## 6. 签到与答题

### 每日签到

```text
签到
```

每天首次签到会获得积分。重复签到不会重复计分。

### 反诈答题

```text
反诈答题
```

机器人发送选择题后，直接回复 `A`、`B`、`C` 或 `D`。题目来自 `source/quiz_bank.json`，初始化时导入数据库。

### 积分查询

```text
我的积分
积分排行
```

排行榜按当前群组统计，私聊积分与群聊积分的上下文可能不同。

## 7. 定时推送

知识图片和案例文本分别来自：

```text
source/knowledge/
source/example/
```

推送时间由 `.env.prod` 配置。群管理员和用户可通过功能开关控制是否接收。批量推送前应确认素材许可、群规和发送频率，避免骚扰或触发平台限制。

## 8. Web 安全大屏

默认登录地址：

```text
http://127.0.0.1:8000/#/login
```

用户名固定为：

```text
admin
```

密码必须由部署者在 `.env.prod` 中设置。项目不提供 `admin/admin` 默认登录。

大屏展示：

- 防护指数和威胁拦截量；
- 防御准备度指标；
- 诈骗类型雷达；
- AI 分析摘要流；
- 24 小时展示曲线；
- 安全研判日报；
- 基于群号哈希生成的虚拟态势地图。

> [!NOTE]
> 地图坐标是用于可视化的虚拟位置，不代表群成员或事件的真实地理位置。趋势预测也是启发式展示，不是训练模型输出。

所有业务 API 需要 JWT。Token 失效时前端会清理登录状态并返回登录页。

## 9. 隐私与日志

数据库可能包含：

- QQ 用户号和群号；
- 命中的消息内容；
- AI 分析输入和输出；
- 对话上下文；
- 答题和积分记录。

部署者应：

1. 明确告知群成员机器人功能；
2. 控制日志和数据保留周期；
3. 限制数据库文件访问权限；
4. 避免把生产数据库用于截图、演示或 Issue；
5. 对导出的数据进行脱敏；
6. 根据当地法律处理删除和访问请求。

## 10. 常见问题

### 为什么登录失败？

- `503`：管理员密码未安全配置；
- `401`：用户名、密码或 Token 错误；
- `429`：短时间失败次数过多。

### 为什么大屏没有数据？

新部署尚未产生检测、答题或 AI 日志时，大部分指标会显示零或默认展示值。先完成数据库初始化并让机器人处理测试事件。

### 为什么题目没有更新？

修改 `source/quiz_bank.json` 后，需要重新运行初始化脚本。脚本按题目文本去重，不会重复导入已有题目。

### 如何报告问题？

普通缺陷使用 GitHub Issue；安全问题使用私密漏洞报告。所有日志和截图必须先去除 QQ 号、Token、密钥和聊天隐私。
