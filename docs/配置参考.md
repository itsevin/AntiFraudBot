# ⚙️ 配置参考

[文档中心](README.md) · [English](en/configuration.md) · [安装与部署](安装部署.md)

AntiFraudBot 使用 NoneBot2 的环境配置机制。`.env` 选择运行环境，`.env.prod` 保存本地生产配置；两者都不应提交，仓库只提供安全模板。

## NoneBot

| 配置项 | 默认/示例 | 说明 |
|---|---|---|
| `SUPERUSERS` | `[]` | NoneBot 超级用户 QQ 号列表 |
| `COMMAND_START` | `[""]` | 命令前缀列表 |
| `SESSION_EXPIRE_TIMEOUT` | `00:03:00` | 会话超时 |
| `LOG_LEVEL` | `INFO` | 日志等级；生产环境不建议长期使用 DEBUG |
| `HOST` | `127.0.0.1` | NoneBot 监听地址 |
| `PORT` | `8080` | NoneBot 端口 |

## Web 后台

| 配置项 | 默认/示例 | 安全要求 |
|---|---|---|
| `WEB_HOST` | `127.0.0.1` | 默认仅本机；公网使用反向代理 |
| `WEB_PORT` | `8000` | Web 服务端口 |
| `WEB_ADMIN_PASSWORD` | 无安全默认值 | 必须至少 12 位且不能是常见弱密码 |
| `WEB_CORS_ORIGINS` | 本机两个来源 | JSON 数组或逗号分隔；禁止 `*` |
| `JWT_EXPIRE_MINUTES` | `1440` | JWT 有效期，单位分钟 |
| `JWT_SECRET` | 自动生成 | 可选；未配置时写入忽略文件 |

推荐公网配置：

```dotenv
WEB_HOST=127.0.0.1
WEB_PORT=8000
WEB_ADMIN_PASSWORD=a-long-random-password
WEB_CORS_ORIGINS=["https://antifraud.example.com"]
JWT_EXPIRE_MINUTES=120
```

## 定时推送

| 配置项 | 默认值 | 范围 |
|---|---:|---|
| `ANTI_FRAUD_KNOWLEDGE_PUSH_HOUR` | `12` | `0–23` |
| `ANTI_FRAUD_KNOWLEDGE_PUSH_MINUTE` | `0` | `0–59` |
| `ANTI_FRAUD_EXAMPLE_PUSH_HOUR` | `12` | `0–23` |
| `ANTI_FRAUD_EXAMPLE_PUSH_MINUTE` | `0` | `0–59` |

## AI 服务

| 配置项 | 说明 |
|---|---|
| `AI_API_KEY` | 模型服务密钥；可选 |
| `AI_API_BASE` | 兼容 OpenAI Chat Completions 的基础地址 |
| `AI_MODEL` | 模型名称 |
| `AI_TIMEOUT` | 请求超时秒数 |

```dotenv
AI_API_KEY=
AI_API_BASE=https://api.deepseek.com/v1
AI_MODEL=deepseek-chat
AI_TIMEOUT=30
```

不要把完整聊天内容无差别发送给外部模型。部署前审核服务商的数据保留和地域政策。

## 智能对话助手

| 配置项 | 默认值 | 说明 |
|---|---:|---|
| `CHATBOT_ENABLED` | `false` | 总开关 |
| `CHATBOT_CONTEXT_TIMEOUT` | `600` | 上下文超时秒数 |
| `CHATBOT_MAX_CONTEXT_ROUNDS` | `5` | 最大保留轮数 |
| `CHATBOT_RAG_ENABLED` | `true` | 基础知识检索开关 |
| `CHATBOT_RAG_TOP_K` | `3` | 返回上下文数量 |
| `CHATBOT_TRIGGER_AT_ME` | `true` | 是否支持 @触发 |
| `CHATBOT_TRIGGER_KEYWORDS` | 中文关键词数组 | 文本触发关键词 |
| `CHATBOT_USE_GROUP_STATS` | `true` | 是否引用群组统计 |
| `CHATBOT_STATS_CACHE_HOURS` | `1` | 统计缓存时间 |

## 阿里云 URL 检测

```dotenv
ALIBABA_CLOUD_ACESS_KEY_ID=
ALIBABA_CLOUD_ACESS_KEY_SECRET=
```

变量名中的 `ACESS` 是项目当前兼容名称。使用最小权限的独立 AccessKey，并定期轮换。不要使用主账号密钥。

## 数据库

```dotenv
SQLALCHEMY_DATABASE_URL=sqlite+aiosqlite:///data/data.db
ALEMBIC_STARTUP_CHECK=false
```

当前默认数据库为 `data/data.db`。该文件可能含隐私数据，必须保持忽略、限制访问并纳入部署者自己的备份策略。

## 配置自检

```bash
poetry run python scripts/check_open_source.py
git status --short
```

如果 `.env`、`.env.prod`、`data.db` 或 `.jwt_secret` 出现在 Git 状态的待提交列表中，应立即停止提交并检查忽略规则。
